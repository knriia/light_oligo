# AGENTS.md

Проект: система синтеза олигонуклеотидов (Lazarus / Free Pascal). Ответы и коммиты на русском.

## Заметки проекта (вне репозитория)

Папка: `D:\info\notes\Работа\Система синтеза олигов\`

- `Бэклог.md` — канбан-доска (Obsidian): критичное, важное, хвосты, идеи.
- `Архитектура\Переезд на чистую архитектуру.md` — план миграции на плоские модули: целевая структура, правила зависимостей, решения, шаги 0–11 с именами веток. Источник истины о том, что сделано и что дальше.

Заметки не копировать в репозиторий. После влития ветки отметить пункт `[x]` в плане.

## Структура

Исходники в `src/<модуль>/`, тесты каждого модуля в `src/<модуль>/tests/`. Модули: `shared`, `platform`, `oligo`, `protocol`, `laser`, `synthesis`, `station`, `manual`; в корне `src/` — `app` (AppComposition, UMainForm). Допустимые зависимости задаёт `scripts/architecture/modules.json`.

## Проверки

- `python scripts/check_architecture.py` (с `PYTHONUTF8=1`) — границы модулей, циклы.
- `scripts\run_tests.cmd` — сборка и запуск всех тестовых проектов.
- `C:\lazarus\lazbuild.exe LightOligo.lpi` — сборка приложения.

## Порядок работы

- Одна задача — одна ветка от свежего `main` (snake_case, имя из плана); перед новой веткой убедиться, что предыдущая влита.
- Рефакторинг, фичи и багфиксы в одной ветке не смешивать.
- После выполнения задачи — ревью отдельным read-only субагентом, затем коммит.
- Коммиты на русском, префикс типа латиницей (`refactor:`, `feat:`, `fix:`, `chore:`), без строки Co-Authored-By.
- При переносе файлов: `git mv`, правка путей в `LightOligo.lpi`, `*.lpi` тестов и `scripts/`; проверять, что каждый `<Filename>` указывает на существующий файл.
