# Ручной чек-лист приёмочного тестирования

Чек-лист выполняется на свежей сборке после закрытия старых экземпляров приложения.
Каждый непройденный пункт фиксируется с шагами воспроизведения, временем, логом и
скриншотом.

## Правила фиксации результата

- [ ] Перед началом остановлены старые экземпляры приложения.
- [ ] Для аппаратных проверок записаны фактические адреса, COM-порт и настройки скорости.
- [ ] Для каждой операции зафиксированы выбранный канал, объём, заданная скорость в `мкл/с` и результат.
- [ ] Команды не повторяются автоматически после ошибки связи.
- [ ] Если движение началось, но завершение не подтверждено, текущий объём считается неизвестным.

## 1. Запуск и главное окно

- [ ] Приложение запускается с пустой конфигурацией.
- [ ] При пустой таблице COM-порт подключается без предварительного добавления дозатора; после создания конфигурации её можно инициализировать отдельно.
- [ ] При отсутствии выбранного COM-порта подключение не выполняется, причина понятна из сообщения или журнала.
- [ ] Последний выбранный COM-порт восстанавливается после перезапуска.
- [ ] Если сохранённый порт временно недоступен, обновление списка не заменяет его случайным портом.
- [ ] Минимальный размер окна сохраняет таблицу, правый отступ и нижнюю панель без наложений.
- [ ] При изменении ширины и высоты таблица, верхние панели и журнал растягиваются корректно.
- [ ] При наличии 15 дозаторов появляется прокрутка, строки не перекрываются.
- [ ] Статус-бар находится в самом низу окна, панель журнала — непосредственно над ним.
- [ ] Разделитель журнала изменяется только с верхней стороны: таблица увеличивается или уменьшается соответственно.
- [ ] Минимальная высота журнала составляет примерно 10 пикселей и он не схлопывается в ноль.
- [ ] При добавлении сообщений журнал прокручивается вниз, новые записи остаются видимыми.

## 2. Конфигуратор

- [ ] Кнопка «Конфигуратор» доступна до подключения устройства.
- [ ] При подключённом устройстве поля конфигуратора остаются доступными и не сереют из-за объёма. При известном положительном объёме попытка изменить поле показывает предупреждение и отменяется; при неизвестном объёме изменения можно применить, но дозатор потребует инициализации.
- [ ] В пустой конфигурации можно создать дозатор.
- [ ] Значения по умолчанию нового дозатора: количество шагов `12000`; при вместимости `250 мкл` максимальная скорость в конфигураторе и начальная скорость операции равны `125 мкл/с` (аппаратный предел — `6000 имп/с`).
- [ ] Стрелки поля «Объём шприца» изменяют значение на `50 мкл` за нажатие вверх или вниз; произвольное значение можно ввести вручную.
- [ ] Изменение вместимости или количества шагов сразу пересчитывает и подставляет максимальную скорость; изменение других полей её не сбрасывает.
- [ ] Индивидуальные кнопки «Инициализировать» в строках и общая «Инициализировать все» в общей панели доступны до подключения; нажатие просит подключить устройство. «Остановить все» находится рядом с групповыми командами и доступна при активных операциях.
- [ ] После подключения доступна инициализация каждого дозатора отдельно и повторная инициализация уже готового дозатора.
- [ ] Количество каналов 2 и 12 принимается, 0, 1 и 13 отклоняются; остальные числовые пределы также проверяются.
- [ ] Проверяются пустые имена и дубли номеров, имён и адресов.
- [ ] Нельзя создать 16-й дозатор.
- [ ] Нельзя уменьшить количество каналов так, чтобы канал забора остался недопустимым.
- [ ] У дозатора с известным положительным объёмом кнопка «Удалить» отключена; после опустошения дозатора она снова активна. Уменьшение вместимости блокируется предупреждением.
- [ ] До подключения корректная конфигурация применяется без инициализации.
- [ ] «Применить» выключена без изменений и включается при изменениях; некорректный ввод показывает ошибку при нажатии.
- [ ] Применение изменённой конфигурации сразу сохраняет её, помечает изменившиеся дозаторы как требующие инициализации и показывает их номера; контролы не сереют, а запуск операций до инициализации показывает предупреждение и не отправляет команду.
- [ ] «Отмена» не изменяет конфигурацию.
- [ ] После инициализации изменённые дозаторы готовы к командам; конфигурация и параметры операций, применённые до инициализации, сохраняются после перезапуска.
- [ ] Текущий объём намеренно не сохраняется в INI и не восстанавливается после перезапуска.
- [ ] Подключение открывает только COM-порт: объём остаётся неизвестным до отдельной инициализации; кнопки движения остаются доступными, но попытка запуска показывает уведомление и не отправляет команду.
- [ ] После успешной инициализации плунжера и подтверждения статуса `Ready` приложение считает шприц пустым: объём известен и равен `0 мкл`.

## 3. Подключение и инициализация

- [ ] Оба дозатора подключены к одной линии RS-485 и имеют разные адреса.
- [ ] При правильном COM-порте кнопка меняется на «Отключить», статус-бар показывает установленную связь.
- [ ] После подключения автоматические запросы и механическая инициализация не запускаются; статус показывает готовые дозаторы из общего списка.
- [ ] В журнале отображается понятный статус каждого дозатора без постоянного дублирования одинаковых TX/RX.
- [ ] Дозатор со статусом «не инициализирован» остаётся подключённым по COM; попытка запустить его команду показывает уведомление. Инициализация из строки затрагивает только этот дозатор.
- [ ] Нажатие индивидуальной кнопки инициализирует только соответствующий дозатор.
- [ ] Инициализация клапана использует канал забора из конфигуратора.
- [ ] Тип клапана определяется приложением автоматически, отдельная карта подключений не задаётся.
- [ ] Для недистрибутивного клапана рабочие каналы нумеруются по часовой стрелке по общему правилу.
- [ ] После клапана выполняется инициализация плунжера.
- [ ] При двух дозаторах сначала запускаются клапаны обоих дозаторов до ожидания их готовности; после готовности клапанов запускаются оба плунжера до ожидания их готовности.
- [ ] После инициализации режим N1 применяется до разблокировки операций.
- [ ] После успешной инициализации выбранные дозаторы показывают `0 мкл` и разблокированы; остальные сохраняют своё состояние.
- [ ] При ошибке инициализации одного дозатора COM остаётся подключённым, успешно инициализированные дозаторы остаются готовы, ошибочный остаётся заблокирован.
- [ ] Неправильный COM-порт не устанавливает связь; отсутствие ответа конкретного дозатора не закрывает COM автоматически.
- [ ] При ошибке или тайм-ауте инициализации объём остаётся неизвестным, операции остаются заблокированными; значение `0 мкл` не выставляется.
- [ ] При нулевых объёмах отключение закрывает порт и возвращает интерфейс в состояние «Отключено».
- [ ] Повторное нажатие «Подключить» после отключения создаёт только одно подключение.

## 4. Состояния и блокировки интерфейса

- [ ] В отключённом состоянии недоступны чекбоксы выбора, поля объёма и скорости, каналы, bypass и четыре кнопки операций каждой строки.
- [ ] До инициализации элементы строк остаются доступными; запуск движения показывает уведомление и не отправляет команду. После инициализации операции выполняются.
- [ ] Во время операции строка блокирует органы управления, кроме поля скорости.
- [ ] Остальные строки во время его работы остаются доступными.
- [ ] После завершения операции строка разблокируется независимо от остальных дозаторов.
- [ ] Во время активной операции нельзя отключиться или закрыть приложение.
- [ ] При заполненных дозаторах отключение и закрытие блокируются списком дозаторов и их объёмов.
- [ ] После опустошения всех дозаторов отключение и закрытие выполняются штатно.
- [ ] При неизвестном объёме новая операция не запускается до успешной повторной инициализации; после неё объём начинается с `0 мкл`, старое значение не восстанавливается.

## 5. Поля операций и клавиатура

- [ ] Объём операции принимает значения от `1` до вместимости шприца.
- [ ] Максимальная скорость в конфигураторе и скорость операции в таблице отображаются в `мкл/с`; значения ограничены калибровкой шприца и аппаратным пределом двигателя.
- [ ] Если в поле скорости таблицы ввести значение выше максимума и подтвердить Enter или покинуть поле, значение заменяется максимальным без предупреждения.
- [ ] Для дозаторов с разными объёмами шприца или количеством шагов одна заданная скорость `мкл/с` преобразуется в разные скорости двигателя.
- [ ] Для калибровок `5000 мкл / 12000 шагов` и `250 мкл / 12000 шагов` заданные `10 мкл/с` дают команды двигателя `24` и `480 имп/с` соответственно.
- [ ] Ноль, отрицательные и превышающие допустимые значения не сохраняются.
- [ ] Изменение полей мышью, стрелками, Enter и потерей фокуса сохраняет корректное значение.
- [ ] Esc возвращает прежнее значение и не закрывает окно.
- [ ] Tab/Enter переводит фокус предсказуемо и не запускает операцию случайно.
- [ ] Изменение вместимости не сбрасывает допустимый объём операции.
- [ ] Изменение максимальной скорости дозатора в конфигураторе не меняет скорость операции в таблице, если она остаётся допустимой.
- [ ] При уменьшении вместимости ниже объёма операции значение корректируется до новой вместимости.
- [ ] Изменение числа каналов или канала забора не сбрасывает объём и скорость операции.

## 6. Одиночные операции

| Операция | Откуда берётся канал | Направление | Ожидаемый результат |
|---|---|---|---|
| Наполнить | Канал забора из конфигуратора | набор | Шприц заполняется до вместимости |
| Набрать | Канал, выбранный в строке | набор | Объём увеличивается на заданное значение |
| Дозировать | Канал, выбранный в строке | выдача | Объём уменьшается на заданное значение |
| Опустошить | Канал, выбранный в строке | выдача | Текущий объём становится нулевым |

- [ ] На пустом дозаторе «Наполнить» набирает весь доступный объём.
- [ ] «Наполнить» использует максимальную скорость из конфигуратора, даже если скорость операции в главной таблице отличается.
- [ ] «Наполнить» использует канал забора из конфигуратора независимо от выбранного канала строки.
- [ ] «Набрать» использует выбранный в строке канал.
- [ ] «Дозировать» использует выбранный в строке канал.
- [ ] «Опустошить» выдаёт весь текущий объём в выбранный канал.
- [ ] Для двухканального дозатора проверены оба канала `ON` и `OFF`.
- [ ] Для десятиканального дозатора проверены первый, средний и последний рабочие каналы.
- [ ] Проверено дозирование в канал, отличный от канала забора.
- [ ] На полном дозаторе повторное «Наполнить» не отправляет команду и показывает предупреждение.
- [ ] Если остаток меньше запрошенного объёма, «Дозировать» завершается ошибкой до движения: частичной дозы нет, учтённый остаток не меняется.
- [ ] На пустом дозаторе «Дозировать» и «Опустошить» не отправляют команду.
- [ ] Если запрошенный объём «Набрать» не помещается целиком, операция отклоняется без отправки команды и без изменения учтённого объёма.
- [ ] После успешной операции обновляются прогресс-бар, текущий объём и журнал.
- [ ] В журнале отдельно видны запуск и завершение операции.
- [ ] Во время движения в последнем столбце строки доступна кнопка «Остановить»; у неактивного дозатора она отключена.
- [ ] Остановка прекращает только выбранный дозатор; при параллельном движении второй продолжает работу.
- [ ] После подтверждённого останова текущий объём становится неизвестным, а операции дозатора блокируются до инициализации.
- [ ] Попытки «Наполнить», «Опустошить», «Набрать» и «Дозировать» до повторной инициализации показывают уведомление и не запускают движение.
- [ ] В смешанной групповой выборке остановленный и неинициализированный дозатор пропускается с уведомлением, а доступные выбранные дозаторы выполняют команду; если доступных нет, команда никому не отправляется.
- [ ] Если ответ на останов не получен, после завершения опроса объём остаётся неизвестным; повторная инициализация возвращает известный объём `0 мкл`.
- [ ] Во время движения измени скорость и подтверди ввод Enter или потерей фокуса: поле скорости и кнопки остаются доступными; обычная команда занятому дозатору показывает уведомление и не отправляется.
- [ ] Убедись на подключённом дозаторе, что после команды `V<n>` скорость оставшейся части текущего хода меняется без остановки.
- [ ] Введи новую скорость в мкл/с, подтверди ввод и проверь, что поле не откатывается, предупреждение о скорости в имп/с не появляется, а устройству отправляется пересчитанная команда `V<n>`.
- [ ] После завершения запусти «Набрать», «Дозировать» или «Опустошить» и проверь, что сохранённая скорость применяется снова.
- [ ] Убедись, что «Наполнить» при запуске использует максимум из конфигуратора; изменение поля во время наполнения меняет только остаток текущего хода.

## 7. Параллельная и групповая работа

- [ ] Запустить операцию на дозаторе 1 и сразу операцию на дозаторе 2: команда второму отправляется до завершения первого.
- [ ] Во время движения дозатора 1 менять вкладку, выбирать строки и пользоваться командами свободного дозатора 2; окно остаётся отзывчивым, команда 2 уходит до завершения движения 1.
- [ ] Во время медленного ответа или инициализации дозатора 1 менять размер окна, прокручивать таблицу и читать журнал; интерфейс не зависает.
- [ ] Повторно нажать команду для дозатора 1, пока он занят: появляется уведомление именно о дозаторе 1, повторная команда не отправляется, дозатор 2 остаётся доступен.
- [ ] Во время отправки команды дозатору 1 сразу отправить другую команду дозатору 2; ответы COM-порта относятся к своим запросам и отображаются у правильных строк.
- [ ] Пока дозатор 1 инициализируется, выполнить команду на готовом дозаторе 2; обе операции выполняются без блокировки интерфейса и без перемешивания ответов.
- [ ] Физически оба дозатора начинают движение без ожидания друг друга.
- [ ] Выбрать оба дозатора и нажать верхнюю кнопку «Наполнить».
- [ ] Выбрать оба дозатора и отдельно проверить «Набрать», «Дозировать» и «Опустошить».
- [ ] В журнале видны запуски всех выбранных дозаторов, а завершение фиксируется отдельно для каждого.
- [ ] Во время движения команды занятой строки остаются доступными для нажатия, но показывают предупреждение и не отправляют дублирующую команду; свободные строки продолжают работать.
- [ ] Во время групповой операции скорость можно менять в активных строках; команда `V<n>` меняет остаток движения соответствующего дозатора, а сохранённое значение применяется к его следующим операциям.
- [ ] Неактивный дозатор остаётся доступным для отдельной команды.
- [ ] Если среди выбранных есть занятый, неинициализированный дозатор или дозатор с bypass, они пропускаются с уведомлением, а команда отправляется остальным доступным дозаторам.
- [ ] Если один план операции не проходит проверку объёма, канала или скорости, группа не запускается целиком.
- [ ] Если ошибка передачи возникает уже после запуска предыдущих дозаторов, последующие команды не отправляются, а уже запущенные операции продолжаются.
- [ ] После завершения группы каждый дозатор получает независимый итоговый объём.
- [ ] При отсутствии выбранных строк верхние кнопки операций недоступны.

## 8. Байпас

- [ ] Запрос `?6` для определения типа клапана и поддержки bypass выполняется после успешной инициализации дозатора.
- [ ] Для недистрибутивного клапана с ответом `i`, `o`, `e` или `b` чекбокс bypass доступен.
- [ ] Для распределительного клапана с числовым ответом чекбокс bypass недоступен.
- [ ] До успешной инициализации и при ошибке запроса `?6` bypass недоступен.
- [ ] Если канал забора и выбранный канал совпадают, попытка включения bypass отклоняется до отправки команды переключения.
- [ ] При разных каналах bypass включается, клапан физически переключается, а четыре операции строки блокируются.
- [ ] При активном bypass нельзя менять канал и запускать операции строки.
- [ ] После снятия bypass канал и операции снова доступны.
- [ ] В смешанной групповой выборке с активным bypass операция не запускается ни для одного выбранного дозатора.
- [ ] После отключения состояние bypass сбрасывается; после следующей успешной инициализации поддержка определяется новым запросом `?6`.

## 9. Фиксированный режим N1

- [ ] В таблице нет столбца режима.
- [ ] Режим N1 фиксирован; пользователь не может выбрать другой режим.
- [ ] При каждой инициализации команда N1 отправляется после инициализации плунжера и до разблокировки операций; простое подключение COM эту команду не отправляет.
- [ ] Расчёт перемещения выполняется с коэффициентом 8 для N1.
- [ ] Пересчёт скорости операции в аппаратные импульсы/с использует базовое количество шагов N1: `количество шагов / объём шприца`; множитель `8` применяется только к числу микрошагов перемещения.

## 10. Журнал и сообщения

- [ ] В журнале есть запуск программы, открытие и закрытие COM-порта, инициализация, запуск и завершение операций.
- [ ] Успешные одинаковые статусы не дублируются без необходимости.
- [ ] Ошибки содержат имя или адрес дозатора и понятную причину.
- [ ] При ошибке движения объём не изменяется самопроизвольно и помечается неизвестным, если завершение не подтверждено.
- [ ] Автоматического повтора команды после ошибки нет.
- [ ] Новая операция с неизвестным объёмом отклоняется с понятным сообщением.
- [ ] Статус-бар показывает «Отключено» либо подключённый COM-порт и число готовых дозаторов в формате `готово дозаторов: N из M`.

## 11. Масштабирование и финальный прогон

- [ ] Повторены ключевые проверки при масштабе Windows 125%.
- [ ] Повторены ключевые проверки при масштабе Windows 150%.
- [ ] При минимальной ширине окна таблица показывает новый последний столбец «Остановить» без обрезания кнопки.
- [ ] Полный прогон выполнен на свежей сборке с двумя дозаторами: двухканальным и десятиканальным.
- [ ] Для каждой операции проверены успешный сценарий, пустой/полный дозатор и недопустимый объём.
- [ ] Проверены одиночные и групповые операции.
- [ ] Проверены разные каналы, bypass и фиксированный режим N1.
- [ ] Все непройденные пункты имеют описание дефекта или явно помечены как отложенные.
- [ ] К переходу к следующему этапу нет нерешённых проблем в блокировках, выборе каналов, объёмах, инициализации и групповых операциях.

## 12. Редактор автоматизации: открытие, сохранение и выполнение

- [ ] Рядом с исполняемым файлом автоматически создаётся папка `protocols`.
- [ ] «Открыть» и «Сохранить как» начинают в папке `protocols`, но позволяют выбрать другой каталог.
- [ ] Первый вызов «Сохранить» и вызов «Сохранить как» для нового сценария предлагают сохранить файл в `protocols`.
- [ ] Обычное «Сохранить» после открытия сценария из другого каталога обновляет именно открытый файл.
- [ ] После перезапуска открывается последний сценарий, включая файл за пределами `protocols`.
- [ ] Сценарий с кириллицей сохраняется и повторно открывается без повреждения текста; UTF-8 BOM при чтении не отображается в редакторе.
- [ ] При несохранённых изменениях открытие другого файла предлагает сохранить, отказаться или отменить действие.
- [ ] При несохранённых изменениях закрытие приложения предлагает сохранить, отказаться или отменить действие.
- [ ] Отмена диалога «Сохранить как», отказ от сохранения и ошибка записи не приводят к потере текущего текста и не открывают другой файл/закрывают приложение.
- [ ] Кнопки стоят справа в порядке «Добавить команду», «Запустить протокол», «Открыть», «Сохранить», «Сохранить как» и имеют одинаковый размер.
- [ ] «Запустить протокол» отключена для пустого редактора и активна для непустого текста.
- [ ] При запуске без подключения приложение предлагает сначала подключить устройство; команды не отправляются.
- [ ] При незаполненных полях, неизвестном имени дозатора, неверном канале, единице или скорости протокол отклоняется до любого движения.
- [ ] Однодозаторная команда дозирует заданный суммарный объём в выбранный канал с указанной скоростью.
- [ ] В команде с несколькими дозаторами проверены общие значения параметров и отдельные значения через /.
- [ ] Проверены единицы нл, мкл, мл, нл/с, мкл/с, мл/с и десятичные значения.
- [ ] Перед каждым набором или дозированием все участвующие клапаны заканчивают переключение до запуска плунжеров.
- [ ] Команда объёмом больше вместимости шприца повторяет набор и дозирование до выполнения суммарного объёма.
- [ ] На дозаторах с разной вместимостью меньший шприц повторно наполняется, пока остальные дозаторы ждут; выдача продолжается синхронными порциями.
- [ ] Наполнение для протокола использует максимальную скорость из конфигуратора, выдача — скорость команды.
- [ ] Несколько команд выполняются по порядку текста; следующая команда не начинается до завершения предыдущей.
- [ ] Остановка одного дозатора или всех дозаторов прерывает протокол; движение нельзя возобновить, затронутые дозаторы требуют инициализации.
- [ ] Во время протокола его дозаторы нельзя инициализировать или использовать для ручных операций; посторонний свободный дозатор остаётся доступен. Конфигуратор и подключение заблокированы, кнопки остановки протокола доступны.
- [ ] Ошибка связи или ошибка статуса во время протокола останавливает текущую группу; объём затронутых дозаторов становится неизвестным.
