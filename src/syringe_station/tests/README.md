# Тесты конфигурации

Автоматические тесты запускаются без дозаторов и COM-порта. Они проверяют
калибровку и ограничение скорости операции максимальным значением, построение
планов операций (в том числе скорость команды «Наполнить» из конфигуратора),
миграцию INI, снимок конфигурации после
инициализации, разделённое подключение и последовательность пакетной
инициализации. Координатор операций проверяет, что новая скорость во время
активного движения сразу отправляется устройству в импульсах/с, хотя поле и
настройки используют мкл/с; новое значение сохраняется для следующих операций.
Проверяется запуск команды на свободном дозаторе, пока другой занят, отказ
повторной команды для работающего адреса и пропуск опросом дозаторов с
незавершённой командой или с операцией протокола. Потоковый тест контроллера
удерживает ответ первого COM-запроса и проверяет, что второй запрос не
вклинивается в транзакцию и получает свой ответ.
Проверяется передача скорости двигателя `4800 имп/с` без программного
ограничения диапазоном `750 имп/с`. «Наполнить» при запуске использует максимум конфигуратора.
Команда `T` проверяется на уровне контроллера; координатор проверяет успешный
останов, отказ подтверждения и блокировку последующих операций до
инициализации. Набор также содержит проверки координатора, конфигурации,
хранения, ограничений и размеров окна. Проверяется сохранение пути последнего
сценария, создание папки `protocols` рядом с приложением и чтение/запись
текстовых сценариев в UTF-8, включая файлы с BOM.
Парсер протокола проверяет обязательные поля, имена дозаторов, единицы объёма и
скорости, списки значений через `/`, перевод единиц в нл и скорость двигателя
для разных шприцев. Модульные тесты исполнителя проверяют барьер клапанов перед
движением, повторное наполнение дозаторов разной вместимости, остановку и
неопределённый результат отправки команды. Работу с реальными дозаторами и
физическую синхронность дополнительно проверяют вручную по UI-чеклисту.
Чек-лист отдельно проверяет отзывчивость окна во время медленного обмена;
консольные тесты не поднимают UI и не заменяют проверку с реальным устройством.

Сборка и запуск должны завершиться без ошибок и падений. Ручные проверки UI и
физическое движение дозаторов перечислены в `UI_CHECKLIST.md`; автоматические
тесты их не заменяют.

Сборка и запуск из каталога проекта:

```text
C:\lazarus\lazbuild.exe tests\configuration_tests.lpi
tests\configuration_tests.exe
```
